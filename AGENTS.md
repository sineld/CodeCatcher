# AGENTS.md

Guidance for AI coding agents (and humans) working on this repository.

## What this is

CodeCatcher is a macOS 15+ menu bar app (SwiftUI, Swift 6, SwiftPM, no third-party dependencies). It reads `~/Library/Messages/chat.db` read-only, finds one-time verification codes in incoming SMS and copies them to the clipboard. The UI is localized into 18 languages.

## Commands

```bash
swift test                                   # all tests; must pass before any commit
swift build                                  # debug build
scripts/build-app.sh                         # release build wrapped as build/CodeCatcher.app
scripts/build-app.sh --install               # also installs to ~/Applications and launches
xcrun swift scripts/make-icon.swift          # regenerates Resources/AppIcon.icns
~/Applications/CodeCatcher.app/Contents/MacOS/CodeCatcher --dry-run 100   # scan recent messages, copy nothing
```

`swift run` is not useful: notifications and localization need the `.app` bundle that `scripts/build-app.sh` produces.

## Layout

```
Sources/CodeCatcher/
  App.swift            app entry, AppModel (polling, clipboard, notifications, settings storage), menu, About, --dry-run
  Language.swift       supported languages, first-launch picker, restart to apply
  MessageStore.swift   SQLite access to chat.db; text or attributedBody (NSUnarchiver)
  CodeExtractor.swift  Rule, Extraction, folding, rules, keyword-nearest candidate selection, noise filters
  RuleBuilder.swift    builds a Rule from a sample SMS and a selected range, verified on the sample
  SettingsView.swift   General, Rules, Keywords, Try It tabs and the rule builder sheet
Resources/
  Info.plist           bundle metadata, CFBundleLocalizations
  AppIcon.icns         generated by scripts/make-icon.swift
  Localizations/<code>.lproj/Localizable.strings
Tests/CodeCatcherTests/  Swift Testing suites, one per source area
docs/README.<code>.md    translated READMEs; README.md (English) is the source
```

## Rules of the road

- **No dependencies.** Use Foundation, SwiftUI, AppKit and the system SQLite.
- **Read-only.** Never write to `chat.db` or anything under `~/Library/Messages`.
- **No real data.** Tests, fixtures, docs and commits must never contain real SMS text, real codes, real phone numbers or personal data. Fabricate examples that follow the real template.
- **Extraction changes need tests.** Add a failing case to `CodeExtractorTests` (or `RuleBuilderTests`) first, then change the code. Keep noise filters conservative: copying a wrong number is worse than copying nothing.
- **Boundaries:** use `CodeExtractor.wordCharacter` for "no letter or digit next to the code". It treats Han, Hiragana, Katakana and Hangul as boundaries because those scripts are written without spaces.
- **Folding:** compare user-facing words through `CodeExtractor.fold`, which keeps one character per character so offsets stay aligned with the original text.
- **Default rules** live in `CodeExtractor.defaultRules` with a fixed UUID; they are seeded into the user's rules once (`AppModel.loadRules`) and are then editable and deletable.

## Localization

- UI strings are English literals in code (`Text("…")`, `Button("…")`, `String(localized: "…")`, …). The English text is the key.
- Every key must exist in all 18 `Resources/Localizations/<code>.lproj/Localizable.strings` files with the same `%@` placeholders. `LocalizationTests` scans `Sources/` and fails on any missing, unused or mismatched key.
- Write interpolations as `\(name)`; never put string literals or `??` inside an interpolation in a UI string (the scanner can't parse them). Compute the value into a local first.
- User data and code values use `Text(verbatim:)`.
- To add a language: add it to `AppLanguage.all`, `CFBundleLocalizations` in `Info.plist`, create its `.lproj`, add `docs/README.<code>.md`, and link it from every README.

## Style

- Match the surrounding code; keep changes small. File and folder names are English.
- Existing code comments are Turkish; new comments may be English. Comment only the why.
- Commit messages: one concise English line, imperative mood.
