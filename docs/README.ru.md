Приложение для строки меню macOS, которое перехватывает одноразовые коды подтверждения в SMS, пересылаемых с вашего iPhone, и копирует их в буфер обмена. У него нет зависимостей: достаточно SwiftUI, Foundation и системной SQLite.

CodeCatcher — бесплатное приложение с открытым исходным кодом. Оно создавалось как личный проект и предоставляется «как есть», без гарантий поддержки или обновлений. Сообщения об ошибках и вклад в проект приветствуются. Если приложение экономит вам время, вы можете поддержать его разработку через [GitHub Sponsors](https://github.com/sponsors/sineld).

## Возможности

- **Не пропускает ни одного сообщения:** все новые SMS, пришедшие после последнего обработанного, обрабатываются по порядку. Начиная с macOS 13 текст большинства сообщений хранится только в столбце `attributedBody`; такие сообщения тоже читаются.
- **Выбирает правильное число:** цифры карт, даты, время, суммы, номера телефонов и номера для отписки от рекламных рассылок отфильтровываются; кодом считается число, ближайшее к ключевому слову.
- **Понимает много языков:** встроены ключевые слова на 18 языках, а сообщения на китайском, японском и корейском, где цифры пишутся вплотную к буквам, тоже обрабатываются. Регистр букв и диакритика не важны, в том числе в турецком: ŞİFRE, şifre и sifre — одно и то же.
- **Правила без regex:** вставьте образец SMS и выделите код; правило будет написано за вас и проверено на образце.
- **GİB e-Arşiv:** пароли к счетам e-Arşiv от Налогового управления Турции, содержащие буквы, перехватываются стандартным правилом.
- **18 языков интерфейса:** язык выбирается при первом запуске, его можно изменить в настройках.
- **Конфиденциальность:** сообщения читаются только на этом Mac и только в режиме чтения; по сети ничего не отправляется.

**Требования:** macOS 15 или новее, Xcode 16 или новее для сборки, а также включённая на iPhone функция «Переадресация» сообщений.

## Установка

### Загрузка

1. Скачайте файл `.dmg` из [последнего релиза](https://github.com/sineld/CodeCatcher/releases/latest). Это универсальное приложение для Mac как с Apple silicon, так и с Intel.
2. Откройте DMG и перетащите CodeCatcher в папку «Программы».
3. Приложение не прошло нотаризацию в Apple, поэтому при первом запуске macOS его блокирует. Попробуйте открыть его один раз, затем перейдите в «Системные настройки» → «Конфиденциальность и безопасность» и нажмите **«Все равно открыть»**. Либо выполните в Терминале:

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeCatcher.app
   ```

### Сборка из исходного кода

```bash
scripts/build-app.sh --install   # builds, installs to ~/Applications and launches
```

**Подпись (рекомендуется):** разрешение «Доступ к диску» привязано к подписи приложения. При ad-hoc-подписи его придётся выдавать заново после каждой пересборки. Чтобы этого избежать, один раз создайте сертификат с именем `CodeCatcher Local` в «Связке ключей» → «Ассистент сертификации» → «Создать сертификат» (тип идентификатора: «Самоподписанный корневой», тип сертификата: «Подписание кода»). Скрипт использует его, если найдёт. Чтобы использовать другой сертификат: `CODESIGN_IDENTITY="…" scripts/build-app.sh`.

### После установки

1. **Доступ к диску:** «Системные настройки» → «Конфиденциальность и безопасность» → «Доступ к диску» → CodeCatcher. Без него `~/Library/Messages/chat.db` не прочитать, а в строке меню отображается значок ⚠︎.
2. На iPhone включите этот Mac в разделе «Настройки» → «Сообщения» → «Переадресация».

## Язык

При первом запуске CodeCatcher спрашивает, какой язык использовать, и запоминает выбор. Позже его можно изменить в разделе «Настройки» → «Основные» → «Язык»; чтобы применить изменение, приложение перезапускается.

Поддерживаемые языки: English, Türkçe, Deutsch, Español, Français, Italiano, Português (Brasil), Nederlands, Polski, Русский, Українська, Kurdî (Kurmancî), Azərbaycan dili, العربية, فارسی, 简体中文, 日本語, 한국어.

Язык интерфейса не ограничивает, какие сообщения перехватываются: ключевые слова для всех поддерживаемых языков по умолчанию активны.

## Как выбирается код

Для каждого нового сообщения по порядку проверяется следующее:

1. **Правила:** проверяются в порядке списка в «Настройки» → «Правила»; первое совпадение определяет код. Знать regex не нужно; см. раздел «Правила по образцу SMS» ниже.

   Стандартное правило ниже добавляется в список один раз, при первом запуске. Как и любое другое правило, его можно изменить и удалить; удалённое правило само не возвращается, его можно восстановить кнопкой **Восстановить удалённые стандартные правила**.

   | Правило | Отправитель | Regex | Почему |
   |---|---|---|---|
   | GİB e-Arşiv | `GIB` | `SIFRENIZ:\s*([A-Z0-9]{4,8})\b` | пароли к счетам e-Arşiv состоят из 6 символов и содержат буквы; некоторые — только из букв |

2. **Ключевые слова:** если в сообщении встречается одно из ключевых слов, кандидатами становятся числа из 4–8 цифр или вида `123 456`. Стандартные ключевые слова охватывают все поддерживаемые языки: `kod, şifre, parola, doğrulama, otp, code, password, passcode, código, codice, şifrə, код, пароль, رمز, کد, 验证码, 动态码, コード, 인증`.
   - **Отфильтровываются:** части дат, времени и сумм; группы цифр телефонов и IBAN; суммы, за которыми следует валюта, например `TL`, `₺` или `USD`; фразы о картах, такие как «ile biten» и «son 4 hanesi»; номера заказов после «no:»; номера для отписки от рекламных рассылок («3340'e RET yaz», «OBRET->3340»).
   - Из оставшихся кандидатов побеждает ближайший к ключевому слову. При равенстве предпочтение отдаётся тому, что стоит после ключевого слова.

Код копируется в буфер обмена, и показывается уведомление. Сообщения старше 10 минут, например синхронизированные после выхода из режима сна, игнорируются.

### Правила по образцу SMS

Если код от какого-то отправителя не перехватывается, откройте «Настройки» → «Правила» → **Создать правило по образцу SMS…**:

1. Введите имя отправителя, например `GIB`.
2. Вставьте SMS целиком.
3. Выделите мышью часть, которую нужно копировать.

CodeCatcher сам пишет правило:
- Неизменные слова перед кодом используются как якорь; если их нет, используются слова после кода.
- Код заменяется шаблоном, соответствующим его форме: только цифры или буквы и цифры, примерно той же длины.
- Перед сохранением правило проверяется на образце SMS. Если оно не захватывает в точности выделенный код, сохранить его нельзя.

Например, если выделить `4DAR7Q` в `… SMS SIFRENIZ: 4DAR7Q B001`, получится правило, которое начинается с `SMS\s+SIFRENIZ\s*:\s*([A-Z0-9]{4,8})`. Оно перехватывает и пароли только из букв, например `ZPQRTT`. Созданный regex показывается в окне, и его можно отредактировать вручную, развернув правило в списке.

На вкладке **Попробовать** можно вставить SMS и сразу увидеть, какой код и какое правило будут выбраны; оттуда тоже можно создать правило.

## Проверка на реальных сообщениях

```bash
~/Applications/CodeCatcher.app/Contents/MacOS/CodeCatcher --dry-run 100          # digits masked
~/Applications/CodeCatcher.app/Contents/MacOS/CodeCatcher --dry-run 100 --plain  # as is
```

Команда просматривает последние N входящих сообщений и для каждого выводит выбранный код и его источник, отмечая позицию кода в тексте как `⟦CODE⟧`. Ничего не копируется. Терминалу нужен «Доступ к диску».

## Разработка

GitHub Actions запускает `swift test` при каждом push и pull request.

```bash
swift test                          # tests
scripts/build-app.sh                # build/CodeCatcher.app (universal: arm64 + x86_64)
scripts/build-app.sh --dmg          # build/CodeCatcher-<version>.dmg for a release
xcrun swift scripts/make-icon.swift # regenerates Resources/AppIcon.icns
```

```
Sources/CodeCatcher/
  App.swift            menu bar, polling loop, clipboard, notification, About, --dry-run
  Language.swift       interface languages, first-launch picker, restart
  MessageStore.swift   read-only chat.db access, attributedBody decoding
  CodeExtractor.swift  language-aware folding, rules, candidate selection and filtering
  RuleBuilder.swift    building a rule from a sample SMS and a selection
  SettingsView.swift   General, Rules, Keywords and Try It tabs
Resources/Localizations/
  <language>.lproj/Localizable.strings   interface translations; en is the source
Tests/CodeCatcherTests/
  CodeExtractorTests.swift   examples derived from real SMS templates (codes are made up)
  RuleBuilderTests.swift     a rule built from a sample works on other SMS of the same template
  RuleStorageTests.swift     default rules are added once, deleted and restored
  MessageStoreTests.swift    reading tests on a temporary chat.db copy
  LocalizationTests.swift    every interface string exists in every language
```

**Переводы:** ключи — это английские строки в `Sources/`. Чтобы добавить или изменить строку, обновите `en.lproj` и все остальные языки; `LocalizationTests` завершается с ошибкой, если отсутствует ключ или плейсхолдер `%@`. Исправления от носителей языка очень приветствуются.

## Конфиденциальность

Сообщения читаются только из `chat.db` на этом Mac, в режиме только для чтения. Ничего не отправляется по сети и не записывается на диск. Все SMS в тестах выдуманы.

Перехваченный код копируется в буфер обмена; приложения, хранящие историю буфера обмена, тоже сохранят эти коды.
